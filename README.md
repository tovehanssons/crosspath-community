# CrossPath

CrossPath är en webbplats som ska fungera som en mötesplats/community för 
aktiva människor. Här ska man kunna träffa nya människor som delar samma intressen,
skapa minnen och hitta gemenskap genom att delta i aktiviteter.

## Tekniker

- HTML
- CSS
- JavaScript
